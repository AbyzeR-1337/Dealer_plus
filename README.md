# 🌍 Global Reseller — симулятор перекупщика (PWA для iPhone)

Игра в стиле «телефон в телефоне» с хакерским интерфейсом: начинаешь с нуля (0 денег, без жилья и работы), устраиваешься на работу, забираешь вещи даром, чинишь, торгуешься и перепродаёшь — и строишь международную торговую империю.

Работает в браузере и ставится на главный экран iPhone через Safari. Деплой — GitHub Actions → GitHub Pages.

## ▶️ Как запустить

1. **Один раз включите Pages:** репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Откройте **Actions → «Build & deploy PWA (GitHub Pages)» → Run workflow** (или просто запушьте коммит).
3. Игра будет по адресу: **https://abyzer-1337.github.io/Dealer_plus/**

### 📲 Установка на iPhone
Safari → открыть ссылку → кнопка **«Поделиться»** → **«На экран „Домой“»**. Игра запускается во весь экран, без адресной строки, и работает офлайн (service worker).

## 🌐 Мультиплеер: онлайн‑рейтинг и друзья

**Сервер уже подключён:** проект Supabase `gyqgkwxbohwmngbspadl` (адрес и публичный anon‑ключ лежат в [`js/config.js`](js/config.js), сборка берёт их оттуда, если в GitHub нет секретов). Рейтинг и друзья работают у всех сразу после деплоя.

Как поднять свой сервер с нуля (бесплатно, 5 минут). Пока сервер не подключён, игра идёт офлайн и вы соревнуетесь с перекупщиками‑ботами:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project** (бесплатный тариф, любой регион, придумайте пароль базы).
2. В проекте откройте **SQL Editor → New query**, вставьте весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run** (должно быть «Success. No rows returned»).
3. **Project Settings → API**: скопируйте **Project URL** (`https://xxxx.supabase.co`) и ключ **anon public**.
4. Впишите их в [`js/config.js`](js/config.js) (это публичные значения) **или** GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**: `SUPABASE_URL` = Project URL и `SUPABASE_ANON_KEY` = anon key (секреты важнее файла). Ключ `service_role` / `secret` никуда не вставляйте.
5. **Actions → Build & deploy PWA → Run workflow**. После деплоя у всех игроков на сайте общий рейтинг.

Без секретов можно проверить онлайн сразу в игре: **Настройки → Мультиплеер → Подключить сервер** (вставить URL и ключ). Кнопка **«Пригласить друга»** делает ссылку, по которой друг попадает на тот же сервер, и ему уходит заявка в друзья (сразу, если он уже в рейтинге, или после регистрации).

В игре: **Рейтинг** → вкладки «Мир / Страна / Друзья», ник, код друга, заявки, эмодзи‑«пинки».

**Меню рейтинга открывается мгновенно:** всё (три рейтинга, друзья, заявки, эмодзи, переводы) приходит одним запросом `gr_home`, последний ответ хранится на телефоне и показывается сразу, а свежие данные подтягиваются в фоне (при запуске и раз в 45 секунд).

**💸 Переводы друзьям (Банк → «Другу» / «Переказ другу»):**
- Только друзьям, комиссия банка 1 % (2,5 % за границу) и налог страны получателя (RU 13 %, UA 18 %, DE 25 %, AE 0 % …), удерживается сразу.
- Деньги идут 2–45 минут, крупные суммы (больше четверти капитала получателя) — «финмониторинг» от 20 минут. Пока перевод в пути, его можно отменить (комиссия не возвращается). Не забрали за 7 дней — деньги возвращаются.
- **Защита от дюпа:** каждое движение денег записано на сервере с порядковым номером. Игра помнит, какие записи уже применила; если откатить сохранение или импортировать старое, сервер вернёт пропущенные записи и отправленное спишется снова, а полученное не придёт второй раз.
- Переводы работают только на одном устройстве за раз (сессия устройства): если открыть аккаунт на другом телефоне, старый теряет право переводить.
- Лимиты считаются от капитала, подтверждённого сервером (он растёт только со временем игры): отправить — до 50 % в сутки, получить — не больше своего капитала (минимум $1000), 10 переводов в сутки, раз в минуту, аккаунт старше 20 минут, уровень 3+, дружба дольше 10 минут, разные устройства.

**Защита от накрутки:**
- Вещами обмениваться нельзя, деньги — только переводами выше, с лимитами, налогом и проверками.
- Клиент не может писать в таблицы напрямую (RLS без политик), всё идёт через серверные функции.
- Сервер ограничивает рост капитала по реальному прошедшему времени и общему времени в игре; подозрительные результаты помечаются и скрываются из рейтинга.
- Регистрация аккаунтов ограничена по IP.

Купленное жильё: живите сами, сдавайте жильцам (выбираете цену — ниже рынка найдут за день, выше — дольше; аренда капает каждый день, бывают задержки и поломки), делайте ремонт до следующего уровня (дороже стоит и сдаётся) и перепродавайте (агентство 5 %). У каждого объявления скрытые факты: часть уже сдана или продана, кто‑то вообще не отвечает, хозяева сдают только семьям / только от месяца / проверяют полицейское досье / просят показать доход, фото бывают прошлогодними (на деле ремонт хуже), можно выторговать скидку на месяц или срезать комиссию, у квартир на продажу бывает долг за коммуналку (не спросили — платите сами). Честный хозяин может попросить задаток, чтобы придержать жильё (зачтётся в оплату; не внесли — могут сдать другим), а мошенники заманивают ценой ниже рынка на 30–45 %, просят «предоплату за бронь» и отказываются от просмотра — переведёте, и «хозяин» пропадёт; пожалуетесь — объявление удалят (если хозяин честный — обидится). Просмотр на такси показывает реальное состояние. Вкладка «Переписка» собирает все диалоги.

- **Мини‑игры и QTE (25+):** осмотр с поиском дефектов и тестами, легит‑чек, ремонт (винты, пайка, шлейфы, установка дисплея, покраска, чистка), взлом прошивки в терминале, упаковка, торг‑QTE, поездка за бесплатными вещами, мусорка, барахолка, аукционы с анти‑снайпингом, смены на работе (курьер, грузчик, кассир, бариста, сортировщик, охранник, такси, оценщик, код‑ревью…), собеседования, казино (шанс и краш), мистери‑боксы, случайные события (карманник, «горячая сделка» за 10 секунд, находки).
- **Экономика:** региональные цены, тренды, события рынка, новости, конкуренты‑перекупщики, которые уводят выгодные лоты.
- **Торговля:** чат с покупателями и продавцами разных характеров, торг, мошенники с фишинговыми ссылками, доставка, претензии и возвраты, отзывы и репутация.
- **Жизнь:** энергия, еда, сон, жильё (от улицы до виллы), налоги и режимы (самозанятый/ИП/компания), банк (кредиты, рейтинг, вклады, карты), биржа, красивые номера и госномера, путешествия с багажом и таможней.
- **Бизнес:** аренда/покупка точек, ремонт, интерьер, полки и цены, найм персонала (продавцы, мастера, закупщики, охрана, управляющие), реклама, кражи, сеть магазинов в разных странах.
- **Прогресс:** уровни и открытие приложений, ежедневные задания, «Путь к империи» из 18 этапов, достижения, коллекции с бонусами, статистика.
- **Телефон:** главный экран как на iPhone — страницы со свайпом, виджеты трёх размеров (часы, журнал, состояние, баланс, свежие объявления, посылки, работа, задания, сообщения, мастерская, VPN), каждое установленное приложение само встаёт на экран. Долгое нажатие — режим редактирования: иконки и виджеты перетаскиваются между местами и страницами, док пересобирается перетаскиванием, 12 обоев, добавление и удаление виджетов. В новом телефоне только системные приложения, остальное качается из **App Market**. **Тоннель VPN** с подпиской открывает скрытые приложения: **Джейлбрейк** и **Тень** (теневой рынок: дешёвый серый товар, часть краденая — изъятие и штраф; отвязка аккаунтов; накрутка отзывов с риском).
- **Банк в стиле банка страны:** у каждого из 16 банков свой интерфейс со своей нижней панелью — Монокіт как моно (сине‑фиолетовый градиент, баланс по центру, наклонная карта, круглые кнопки, белый лист «Операції»), Т‑Копилка как Т‑Банк (истории, «Все счета», жёлтые акценты), Каспер/AliPey — суперапп с сеткой сервисов, N27 и Monzi — минималистичные необанки, Chaze, mBanko, Boursa+, Finecco, MUFJ, Emirat — классические банки, Ziraatt, TBS, K‑Bang, Беларусик — большая карточка счёта и круглое меню. Оформление можно сменить на любое другое (🎨). У каждого банка свой набор карт (у Монокота — Чорна, Біла, віртуальна, Platinum, Iron, ФОП, студентська; у Т‑Копилки — Black, Platinum, Drive, All Airlines, Premium, Бизнес; у Chaze — Freedom, Sapphire, Reserve, Amazin, Ink и т.д.): у карты есть условия оформления (уровень, кредитный рейтинг, ИП, деньги на счёте), цена выпуска и доставка курьером; бонусы работают по‑настоящему — ежедневный кэшбэк по категориям трат, кредитный лимит, скидка на билеты. Основную карту можно выбрать, лишние — закрыть.
- **Переписка и поддержка:** покупатели с характером и стилем письма задают вопросы по категории; честный, уклончивый или ложный ответ; ложь становится доказательством в спорах. Служба поддержки решает споры, принимает жалобы на мошенников, обжалование отзывов, гарантию сделки.
- **Ремонт:** запчасти под модель (оригинал / копия / б/у с донора), расходники, 16 инструментов, разборка доноров, ремонт в несколько этапов.
- **Работа:** первая заявка — сразу с начала игры (резюме уже готово), следующая — через 3 минуты. Для отдельных вакансий нужны документы с таймерами оформления (медкнижка, справка о несудимости, права, сертификат).
- **Казино:** слоты, европейская рулетка, блэкджек, кости, «шанс» и краш — только игровые деньги.
- **Фото без лагов:** каждое фото предмета один раз превращается в обычную картинку (`js/ui/bitmap.js`), галереи листаются свайпом.
- **«Даром»:** почти всё — дешёвый хлам; ценное редко, его разбирают за минуты, гонка за ним почти невыигрышная, часть «подарков» — развод с «оплатой доставки».
- **Мини‑игры на действия (40+):** фото и текст объявления, сдача на кассе, сортировка свайпом, ловля коробок, поимка воришек, инвентаризация (пары), код загрузчика, отмычка, кодовый замок с подсказками 🟢🟡, взвешивание золота, подсчёт овец перед сном, блины дома, найди отличие; на сменах задания чередуются, новые подработки.
- **Умные многошаговые головоломки (`js/mini/proc.js`, `lab.js`, `life.js`):** каждое действие — цепочка шагов с журналом, как в жизни, и каждый раз собирается по‑новому.
  - **Phone Lab:** джейлбрейк, рут и перепрошивка из 13 видов шагов: комбинации кнопок для DFU / recovery / download / fastboot‑меню, выбор прошивки (идентификатор, подпись, Restore vs Update, регион и откат загрузчика), цепочка эксплойта в матрице, патч ядра со сторожевым таймером, поиск сигнатуры в hex‑дампе, регистр по битам, команды из гайда в терминале, тест‑поинт на плате, сверка хеша, разбор краш‑лога, прошивка с отходящим кабелем и всплывающими окнами, первая настройка (язык, дата для сертификата, PIN с пластика SIM, Wi‑Fi с наклейки роутера).
  - **«Даром»:** написать дарителю с учётом его условия, самый быстрый маршрут, подъезд и этаж по номеру квартиры, домофон по переписке, свой пакет у двери — а соперник в это время едет, ошибки дарят ему время.
  - **Карманник:** запомнить приметы и найти вора в толпе, погоня по подсказкам на развилках, схватить. Не поймал — успей заблокировать карту в банковском приложении, пока вор тратит деньги.
  - **Барахолка:** торг правдивыми аргументами (реальные дефекты, возраст модели, честная цена); враньё злит продавца. **Найденный кошелёк:** найти настоящего владельца по пропуску или по описанию содержимого.

## 🛠 Разработка

Без сборщика — чистые ES‑модули.

```bash
python3 -m http.server 8080      # открыть http://localhost:8080
node scripts/check.mjs           # синтаксис + headless смоук‑тест логики
node scripts/build.mjs           # сборка в ./dist (то же делает CI)
```

Структура: `js/core` — состояние, валюты, i18n; `js/data` — страны и каталог; `js/game` — симуляция; `js/ui` — оболочка телефона и SVG‑арт; `js/mini` — мини‑игры; `js/apps` — приложения.

### 🎨 Спрайты предметов

- Исходные листы лежат в `assets/src/` (в сайт не попадают). `python3 scripts/cut_sprites.py` (нужны `rembg`, Pillow, numpy, OpenCV) вырезает каждый предмет из фона нейросетью ISNet и собирает `assets/sheets/sheet*.webp` с прозрачностью (×2, с повышением резкости); затем `python3 scripts/fit_sprites.py` пишет точные рамки предметов в `js/data/sprite_fit.js`.
- `python3 scripts/make_photos.py` генерирует фотофоны `assets/photo/*.webp`: простыня, плед, диван, ковёр, ламинат, дубовый и ореховый стол, мрамор, плитка, коврик для резки, кожаное сиденье, картон, бетон, а для машин — двор с панельками, двор со снегом, гараж, дача, вечерняя улица. `js/ui/photo.js` ставит предмет на фон с тенью по направлению света, балансом белого (дневной свет, лампа, вспышка), виньеткой и шумом матрицы.
- Ракурсы (`js/data/views.js`): у телефонов экран, задняя крышка, левый и правый торец, низ; у машин два борта и крупные планы; у остальных — спереди, слева, справа и крупно. Продавец выкладывает только часть ракурсов, а на осмотре видно всё.
- Координаты спрайтов и теги (категория, тип, цвет, металл, ключевые слова моделей) — в `js/data/sprites.js`, координаты в пикселях исходного листа 1536×1024.
- `js/ui/sprite_art.js` подбирает спрайт под предмет (тип, цвет, металл, ключевые слова) и при необходимости перекрашивает его; если подходящего спрайта нет — используется процедурный рисунок.
- Чтобы добавить новый лист: положить его как `assets/src/sheetN.png` (1536×1024), добавить лист в `SHEETS` и строки спрайтов в `js/data/sprites.js`, запустить `cut_sprites.py` и `fit_sprites.py`, а файл — в список `ART` в `sw.js`. Модели только со спрайтом описываются через `{ sprite: 'id' }` (см. `js/data/models_extra.js`).
