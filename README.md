# 🌍 Global Reseller — симулятор перекупщика (PWA для iPhone)

Игра в стиле «телефон в телефоне» с хакерским интерфейсом: начинаешь с нуля (0 денег, без жилья и работы), устраиваешься на работу, забираешь вещи даром, чинишь, торгуешься и перепродаёшь — и строишь международную торговую империю.

Работает в браузере и ставится на главный экран iPhone через Safari. Деплой — GitHub Actions → GitHub Pages.

## ▶️ Как запустить

1. **Один раз включите Pages:** репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Откройте **Actions → «Build & deploy PWA (GitHub Pages)» → Run workflow** (или просто запушьте коммит).
3. Игра будет по адресу: **https://abyzer-1337.github.io/Dealer_plus/**

### 📲 Установка на iPhone
Safari → открыть ссылку → кнопка **«Поделиться»** → **«На экран „Домой“»**. Игра запускается во весь экран, без адресной строки, и работает офлайн (service worker).

## 🌐 Мультиплеер: онлайн‑рейтинг и друзья

**Сервер уже подключён:** проект Supabase `gyqgkwxbohwmngbspadl` (адрес и публичный anon‑ключ лежат в [`js/config.js`](js/config.js), сборка берёт их оттуда, если в GitHub нет секретов). Рейтинг и друзья работают у всех сразу после деплоя.

Как поднять свой сервер с нуля (бесплатно, 5 минут). Пока сервер не подключён, игра идёт офлайн и вы соревнуетесь с перекупщиками‑ботами:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project** (бесплатный тариф, любой регион, придумайте пароль базы).
2. В проекте откройте **SQL Editor → New query**, вставьте весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run** (должно быть «Success. No rows returned»).
3. **Project Settings → API**: скопируйте **Project URL** (`https://xxxx.supabase.co`) и ключ **anon public**.
4. Впишите их в [`js/config.js`](js/config.js) (это публичные значения) **или** GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**: `SUPABASE_URL` = Project URL и `SUPABASE_ANON_KEY` = anon key (секреты важнее файла). Ключ `service_role` / `secret` никуда не вставляйте.
5. **Actions → Build & deploy PWA → Run workflow**. После деплоя у всех игроков на сайте общий рейтинг.

Без секретов можно проверить онлайн сразу в игре: **Настройки → Мультиплеер → Подключить сервер** (вставить URL и ключ). Кнопка **«Пригласить друга»** делает ссылку, по которой друг попадает на тот же сервер, и ему уходит заявка в друзья (сразу, если он уже в рейтинге, или после регистрации).

В игре: **Рейтинг** → вкладки «Мир / Страна / Друзья», ник, код друга, заявки, эмодзи‑«пинки».

**Меню рейтинга открывается мгновенно:** всё (три рейтинга, друзья, заявки, эмодзи, переводы) приходит одним запросом `gr_home`, последний ответ хранится на телефоне и показывается сразу, а свежие данные подтягиваются в фоне (при запуске и раз в 45 секунд).

**💸 Переводы друзьям (Банк → «Другу» / «Переказ другу»):**
- Только друзьям, комиссия банка 1 % (2,5 % за границу) и налог страны получателя (RU 13 %, UA 18 %, DE 25 %, AE 0 % …), удерживается сразу.
- Деньги идут 2–45 минут, крупные суммы (больше четверти капитала получателя) — «финмониторинг» от 20 минут. Пока перевод в пути, его можно отменить (комиссия не возвращается). Не забрали за 7 дней — деньги возвращаются.
- **Защита от дюпа:** каждое движение денег записано на сервере с порядковым номером. Игра помнит, какие записи уже применила; если откатить сохранение или импортировать старое, сервер вернёт пропущенные записи и отправленное спишется снова, а полученное не придёт второй раз.
- Переводы работают только на одном устройстве за раз (сессия устройства): если открыть аккаунт на другом телефоне, старый теряет право переводить.
- Лимиты считаются от капитала, подтверждённого сервером (он растёт только со временем игры): отправить — до 50 % в сутки, получить — не больше своего капитала (минимум $1000), 10 переводов в сутки, раз в минуту, аккаунт старше 20 минут, уровень 3+, дружба дольше 10 минут, разные устройства.

**Защита от накрутки:**
- Вещами обмениваться нельзя, деньги — только переводами выше, с лимитами, налогом и проверками.
- Клиент не может писать в таблицы напрямую (RLS без политик), всё идёт через серверные функции.
- Сервер ограничивает рост капитала по реальному прошедшему времени и общему времени в игре; подозрительные результаты помечаются и скрываются из рейтинга.
- Регистрация аккаунтов ограничена по IP.

## 🎮 Что есть в игре

- **🅿️ Парковка (Недвижимость → Парковка):** места под машины зависят от того, где вы живёте.
  - **🚧 Место во дворе за шлагбаумом** — в многоквартирных домах, где есть двор. Нужны пропуск от УК/ОСББ, а если квартира съёмная — ещё согласие хозяина (может отказать, особенно если у вас есть пометки в деле).
  - **🅿️ Подземный паркинг** — только в новостройках и домах с евроремонтом. Место сдаёт сосед: нужны договор и номер машины в системе доступа.
  - **🏚 Гараж в ГСК** — не в центре. Нужны доверенность у нотариуса, взнос и пропуск, плюс ежемесячные взносы.
  - **🏢 Охраняемая стоянка** — есть везде, без документов, но дороже.
  - **🌳 Газон у подъезда** — бесплатно и незаконно: по утрам эвакуатор, штраф и штрафстоянка.
  - **🏗 Свой гараж на участке** — только в своём доме, в котором вы живёте. Нужно разрешение на строительство (~3 дня, с пометками в деле дольше, могут отказать — тогда подаёте заново), потом стройка 2 дня. Даёт +2 места навсегда.
  - **Сначала сходите посмотреть.** Из дома не видно, есть ли места: во двор и в подземный паркинг идти 5 минут, на стоянку 15, в ГСК 25. Откроется схема со всеми местами: занято, сдаётся, продаётся, зарезервировано или просто пусто (хозяин в отъезде — место не свободно). Бывает, что свободных мест нет вообще: во дворе примерно в половине случаев, в подземном паркинге — примерно в одном из шести. Увиденное устаревает: места занимают другие (пока вы торгуетесь — тоже), а раз в два дня картина полностью меняется, и нужно смотреть заново.
  - **Место можно купить.** В подземном паркинге и в ГСК часть мест продаётся. Продавец тоже накидывает цену, глядя на ваши деньги (до +50 %), и с ним так же можно торговаться. Нужны договор купли‑продажи у нотариуса и регистрация права собственности (2 дня). За своё место не платят аренду (в ГСК остаются взносы), его не отберут и цену не поднимут; оно остаётся вашим после переезда и продаётся обратно за 85 % рыночной цены.
  - **Торг с владельцем.** Владелец смотрит на ваш капитал и машину и накидывает к обычной цене тем больше, чем вы богаче (рост замедляется), умноженное на его жадность. Это можно оспорить:
    - аргументы: рыночная цена, «сниму надолго и заплачу за 2 месяца вперёд», «машины не мои» (жадный только разозлится), официальный договор (тот, кто сдаёт без налогов, это не любит);
    - мини‑игра «убедить»;
    - отказ платить повышенную — честный владелец чаще соглашается на обычную цену, жадный предложит половину надбавки или скажет «ищите другое место».
    У каждого владельца ограниченное терпение.
  - **Раз в месяц владелец снова смотрит на ваши деньги** и может попросить больше. Не ответите за 2 дня — либо цена вырастет, либо место отдадут другому.
  - **Платежи и переезд.** Просрочка больше 2 дней — место забирают. Переехали — места во дворе, в паркинге и на газоне пропадают. Машины сверх мест стоят где попало, и их тоже может увезти эвакуатор.
- **🛠 Свои мини‑игры у каждого ремонта (46 штук):** телефон — прогреть клей феном (не перегреть), вскрыть в правильном порядке (сначала отключить батарею, иначе искра), вытянуть клеевые ленты батареи медленно, отмыть плату в ультразвуке, выправить корпус прессом, проверить звук; ноутбук — винты разной длины по своим отверстиям (длинный в короткое — пробьёте плату), клавиши по местам, термопаста крестом, поиск КЗ тепловизором, момент затяжки петель; приставка — разборка по порядку, ток лазера, калибровка стика, УФ‑отбеливание; машина — гайки звёздочкой и давление в шинах, сканер OBD (по коду выбрать деталь) + болты по схеме + холостые обороты, уровень ATF, прозвонка предохранителей, PDR‑вмятины, герметик по проёму стекла, снятие и регулировка фары; обувь, одежда, сумки — клей по контуру подошвы и пресс, распарить залом, шов зигзагом, молния, покраска уреза, форма паром; часы — крышка ключом по выемкам и таймграфер; украшения — лапки крест‑накрест, шперак, пайка горелкой; велосипеды — восьмёрка колеса, калипер, мёртвая банка батареи; инструменты — настройка струны, анкер, клей в трещину. Перед ремонтом видно все этапы.
- **💾 Носители и телефоны — полностью только на ПК:** с телефона через переходник видно только папки и число файлов. Открыть файлы, найти ценное, подобрать PIN или пароль и разобраться с вымогателем можно только в «Проводнике» на ПК.
- **🦠 Вирусы на вашем ПК:** запустили подозрительный .exe или просто открыли заражённую флешку (автозапуск) — и можно получить **винлокер** (весь экран: «компьютер заблокирован, переведите N»; заплатить — код приходит не всегда, ввести код, найти его на сайте антивируса раз в игровой час или переустановить Windows с флешки) или **трояна с майнером**: скрытые процессы под системными именами (svch0st.exe, RuntimeBroker32.exe…) грузят процессор под 100 %, ПК загружается дольше, окна открываются с задержкой («Не отвечает…»), установка систем и тесты идут медленнее, растёт счёт за свет, а стилер раз в несколько часов списывает деньги с карты. Лечение — «Диспетчер задач»: снять задачу (процесс вернётся, пока файл на диске) и удалить файл; «Защитник» ловит примерно половину. Снимете настоящий системный процесс (csrss.exe и т. п.) — синий экран и перезагрузка. В командной строке есть `tasklist` и `taskkill /im`.
- **📋 Аукцион: «Мои лоты» справа:** вкладка у правого края и кнопка в шапке открывают панель — лоты, где вы ставили (лидирую/перебили, текущая цена, моя ставка, таймер, история ставок, кнопка «Перебить»), ваши вещи на аукционе (старт, текущая ставка, сколько получите после комиссии, история) и итоги (выиграл, упустил, продал, без ставок, аннулирован).
- **⚖️ Баланс:** у краденого след после любой чистки не меньше 17 %, скупщик платит 20–30 %, заказчики в Тени считают цену с учётом следа, «Показ покупателю» поднимает цену не больше чем на 10 %.
- **🖥 «Мой ПК» как Windows:** «Компьютер» / «Сборка» → «Включить компьютер» — загрузка (быстрее на мощном ПК), рабочий стол с иконками, окна, «Пуск» и панель задач с часами. Внутри: «Этот компьютер» (характеристики и диски), «Проводник» (свой диск C: с документами и любые флешки, диски, телефоны и купленные ноутбуки со склада — с их настоящими файлами), **AIDO64** (стресс‑тест/SMART/журнал BIOS: находит скрытые неисправности, температуры, бенчмарк), **Сервис ПК** (замена любой комплектующей собранного ПК на деталь со склада с проверкой совместимости, разборка на детали, чистка от пыли с заменой термопасты, переустановка ОС, «работать на нём»), «Защитник» (вирусы с подключённых устройств — в карантин до запуска), командная строка (`help`, `systeminfo`, `chkdsk`, `scan`, `ping`…), майнер на видеокарте (доход в пул против счёта за свет каждый час), «Сапёр», «Блокнот», браузер. На странице вещи — «Подключить к ПК».
- **🚨 Тень: краденое со следами:** товары помечены — 🔥 краденое (лента «В РОЗЫСКЕ», какие следы: IMEI в чёрном списке, аккаунт владельца, серийник в базе, гравировка, бирки магазина, номер рамы/VIN, номера, приметный цвет), 📦 серый импорт, 🎭 реплики 1:1; часть краденого продают без пометки (проверьте «Пробить по базе розыска»). Следы убираются у «мастеров» (через VPN, иногда халтура или пропадают с деньгами) или самому мини‑играми; от каждого остаётся немного «перебивки», поэтому риск никогда не ноль. Полиция проверяет вещь 3 раза за ~5 дней, а покупатель — после продажи: шанс ≈ 3 % + 45 % × след (след никогда не опускается ниже 17 %; нетронутое краденое находят примерно в 2–3 случаях из 3–4, полностью почищенное — примерно в 3 из 10 ещё до продажи). Нашли — изъятие или возврат денег покупателю, штраф и пометка в деле. Краденое со следами и продаётся дешевле. Новое в Тени: заказы «без вопросов», скупщик (забирает краденое сразу и без последствий, но за 20–30 % цены), документы «под ключ», «подчистить личное дело».
- **🚗 Реальные цены на машины:** амортизация как на живом рынке (−5–10 % при выезде из салона, потом 4–8 % в год, Toyota и «Гелик» держат цену, китайцы и электромобили дешевеют быстрее), у старых машин есть «пол», мягче влияние пробега и износа; цены по странам с учётом пошлин и утильсбора (Россия ×1,38, Украина ×1,42, Турция ×1,75, Япония ×0,82…). Средняя машина: около 1,9 млн ₽ в Москве и около 715 тыс. ₴ в Киеве.
- **💳 Карты листаются свайпом:** на главном экране банка (во всех оформлениях) карты листаются влево‑вправо как в приложении, с точками, названием карты и кнопкой «Сделать основной»; последняя «карта» — оформить новую.
- **🛡 Стёкла и чехлы (Розетко / ДНК / …):** в магазине железа раздел «Стёкла и чехлы» — защитное стекло, стекло 9D, силиконовый и оригинальный чехол под **конкретную модель** телефона (на другую не подойдут). Курьер привозит в течение часа, стекло клеится мини‑игрой (протереть пыль, положить ровно; криво — пузыри или испорченное стекло), чехол надевается и снимается. Надетые поднимают цену телефона на 2,5–5 % каждый.
- **🔁 Переспросить хозяина квартиры:** любой вопрос можно задать снова через 1,5 игровых часа — сданная квартира может освободиться, молчащий хозяин — ответить, «без торга» — смениться скидкой, свободная — уйти другим.
- **🔍 Осмотр на Оликсе / Авитоне для торга:** всё, что нашли на осмотре и чего не было в объявлении, можно предъявить продавцу — цена сбивается по серьёзности дефектов (упрямые уступают меньше); нашли «всё как в объявлении» — можно попросить скидку за быструю покупку. При продаже на личной встрече — «Показ покупателю»: коробка, чек, здоровье батареи, «не вскрывался», стекло и чехол в подарок, «дайте всё проверить», расхвалить (мини‑игра) — цена растёт до +10 %; неправда рискованна — покупатель может проверить и снизить цену или уйти.
- **🧾 Напоминания про налоги:** в 18:00 и 22:00, если налог за день не оплачен, в 23:30 — последний шанс; при долге — каждые 6 часов с числом дней до принудительного списания; без регистрации — предупреждение, когда доход растёт. Выключается в «Госуслугах».
- **🏠 Недвижимость как в жизни:** вкладки «Снять / Купить / Мои дома / Коммерция». Объявления вашего города с настоящими фото (комнаты, кухни, ванные, фасады — 152 FLUX‑снимка): койка в хостеле, комната, студия, 1‑, 2‑, 3‑комнатные, таунхаус, дом с участком, пентхаус, вилла; разная площадь, этаж, метро, район и пять видов состояния — обшарпанная, бабушкин ремонт, косметика, евроремонт, дизайнерская (влияют на цену и сон). Аренда вперёд за сутки/неделю/месяц (месяц дешевле, но залог и комиссия агентства), автопродление, просрочка и выселение. Купленное жильё: живите сами, сдавайте жильцам (выбираете цену — ниже рынка найдут за день, выше — дольше; аренда капает каждый день, бывают задержки и поломки), делайте ремонт до следующего уровня (дороже стоит и сдаётся) и перепродавайте (агентство 5 %). Каждый новый игрок начинает в комнате, оплаченной на неделю; старым сохранениям дана та же неделя минус прожитые дни, своё жильё переехало в «Мои дома».
- **💬 Сначала напишите хозяину:** кнопки «Снять» и «Купить» открываются только после ответа «да, ещё свободна». - **Банк в стиле банка страны:** у каждого из 16 банков свой интерфейс со своей нижней панелью — Монокіт как моно (сине‑фиолетовый градиент, баланс по центру, наклонная карта, круглые кнопки, белый лист «Операції»), Т‑Копилка как Т‑Банк (истории, «Все счета», жёлтые акценты), Каспер/AliPey — суперапп с сеткой сервисов, N27 и Monzi — минималистичные необанки, Chaze, mBanko, Boursa+, Finecco, MUFJ, Emirat — классические банки, Ziraatt, TBS, K‑Bang, Беларусик — большая карточка счёта и круглое меню. Оформление можно сменить на любое другое (🎨). У каждого банка свой набор карт (у Монокота — Чорна, Біла, віртуальна, Platinum, Iron, ФОП, студентська; у Т‑Копилки — Black, Platinum, Drive, All Airlines, Premium, Бизнес; у Chaze — Freedom, Sapphire, Reserve, Amazin, Ink и т.д.): у карты есть условия оформления (уровень, кредитный рейтинг, ИП, деньги на счёте), цена выпуска и доставка курьером; бонусы работают по‑настоящему — ежедневный кэшбэк по категориям трат, кредитный лимит, скидка на билеты. Основную карту можно выбрать, лишние — закрыть.
- **Переписка и поддержка:** покупатели с характером и стилем письма задают вопросы по категории; честный, уклончивый или ложный ответ; ложь становится доказательством в спорах. Служба поддержки решает споры, принимает жалобы на мошенников, обжалование отзывов, гарантию сделки.
- **Ремонт:** запчасти под модель (оригинал / копия / б/у с донора), расходники, 16 инструментов, разборка доноров, ремонт в несколько этапов.
- **Работа:** первая заявка — сразу с начала игры (резюме уже готово), следующая — через 3 минуты. Для отдельных вакансий нужны документы с таймерами оформления (медкнижка, справка о несудимости, права, сертификат).
- **Казино:** слоты, европейская рулетка, блэкджек, кости, «шанс» и краш — только игровые деньги.
- **Фото без лагов:** каждое фото предмета один раз превращается в обычную картинку (`js/ui/bitmap.js`), галереи листаются свайпом.
- **«Даром»:** почти всё — дешёвый хлам; ценное редко, его разбирают за минуты, гонка за ним почти невыигрышная, часть «подарков» — развод с «оплатой доставки».

- **Умные многошаговые головоломки (`js/mini/proc.js`, `lab.js`, `life.js`):** каждое действие — цепочка шагов с журналом, как в жизни, и каждый раз собирается по‑новому.
  - **Phone Lab:** джейлбрейк, рут и перепрошивка из 13 видов шагов: комбинации кнопок для DFU / recovery / download / fastboot‑меню, выбор прошивки (идентификатор, подпись, Restore vs Update, регион и откат загрузчика), цепочка эксплойта в матрице, патч ядра со сторожевым таймером, поиск сигнатуры в hex‑дампе, регистр по битам, команды из гайда в терминале, тест‑поинт на плате, сверка хеша, разбор краш‑лога, прошивка с отходящим кабелем и всплывающими окнами, первая настройка (язык, дата для сертификата, PIN с пластика SIM, Wi‑Fi с наклейки роутера).
  - **«Даром»:** написать дарителю с учётом его условия, самый быстрый маршрут, подъезд и этаж по номеру квартиры, домофон по переписке, свой пакет у двери — а соперник в это время едет, ошибки дарят ему время.

## 🛠 Разработка

Без сборщика — чистые ES‑модули.

```bash
python3 -m http.server 8080      # открыть http://localhost:8080
node scripts/check.mjs           # синтаксис + headless смоук‑тест логики
node scripts/build.mjs           # сборка в ./dist (то же делает CI)
```

Структура: `js/core` — состояние, валюты, i18n; `js/data` — страны и каталог; `js/game` — симуляция; `js/ui` — оболочка телефона и SVG‑арт; `js/mini` — мини‑игры; `js/apps` — приложения.

### 🎨 Спрайты предметов

- Исходные листы лежат в `assets/src/` (в сайт не попадают). `python3 scripts/cut_sprites.py` (нужны `rembg`, Pillow, numpy, OpenCV) вырезает каждый предмет из фона нейросетью ISNet и собирает `assets/sheets/sheet*.webp` с прозрачностью (×2, с повышением резкости); затем `python3 scripts/fit_sprites.py` пишет точные рамки предметов в `js/data/sprite_fit.js`.
- `python3 scripts/make_photos.py` генерирует фотофоны `assets/photo/*.webp`: простыня, плед, диван, ковёр, ламинат, дубовый и ореховый стол, мрамор, плитка, коврик для резки, кожаное сиденье, картон, бетон, а для машин — двор с панельками, двор со снегом, гараж, дача, вечерняя улица. `js/ui/photo.js` ставит предмет на фон с тенью по направлению света, балансом белого (дневной свет, лампа, вспышка), виньеткой и шумом матрицы.
- Ракурсы (`js/data/views.js`): у телефонов экран, задняя крышка, левый и правый торец, низ; у машин два борта и крупные планы; у остальных — спереди, слева, справа и крупно. Продавец выкладывает только часть ракурсов, а на осмотре видно всё.
- Координаты спрайтов и теги (категория, тип, цвет, металл, ключевые слова моделей) — в `js/data/sprites.js`, координаты в пикселях исходного листа 1536×1024.
- `js/ui/sprite_art.js` подбирает спрайт под предмет (тип, цвет, металл, ключевые слова) и при необходимости перекрашивает его; если подходящего спрайта нет — используется процедурный рисунок.
- Чтобы добавить новый лист: положить его как `assets/src/sheetN.png` (1536×1024), добавить лист в `SHEETS` и строки спрайтов в `js/data/sprites.js`, запустить `cut_sprites.py` и `fit_sprites.py`, а файл — в список `ART` в `sw.js`. Модели только со спрайтом описываются через `{ sprite: 'id' }` (см. `js/data/models_extra.js`).
